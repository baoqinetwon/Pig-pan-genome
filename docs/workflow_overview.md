# Workflow overview

This repository is organized as modular analysis scripts for the pig graph pangenome and SV study.

1. Build graph pangenome and indexes.
2. Discover SVs, SNPs, and Indels from long-read data and assemblies.
3. Perform population-level SV calling, filtering, frequency estimation, LD, Fst, phylogeny, and population-structure analysis.
4. Genotype SVs from short-read WGS using VG/Giraffe.
5. Construct and evaluate the SV imputation panel.
6. Process RNA-seq data and perform cis-eQTL mapping.
7. Conduct ASE, GRN, heritability partitioning, effect-size analysis, and functional annotation.
8. Use the external GWAS/fine-mapping repository for association analyses.
