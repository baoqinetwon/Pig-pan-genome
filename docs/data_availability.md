# Data availability

This GitHub repository stores code, workflow notes, and small examples only.

Large files should be released through the associated manuscript/database rather than GitHub, including:

- long-read SV VCFs
- graph-genotyped short-read SV VCFs
- PGVRP/panel files
- RNA-seq expression matrices
- eQTL summary statistics
- GWAS summary statistics
- large annotation BED files and indexes
- graph index files

Recommended manuscript wording can refer to the PIGSVOME database and other public repositories where applicable.
