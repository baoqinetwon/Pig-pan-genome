# Data availability

This GitHub repository stores code, workflow notes, and small examples only. Large processed datasets supporting this study are available through the PIGSVOME database Download page:

https://pigsvome.bmyjy.org.cn/Help/Download

The downloadable datasets include:

- reference genome of Sscrofa11.1
- reference genome annotation of Sscrofa11.1 (v113)
- structural variant (SV) site information from ONT samples
- structural variant (SV) site information in PGSVRP
- gene read counts
- gene expression (TPM) matrices for three tissues
- summary statistics of significant variant-gene expression associations for three tissues
- GWAS results for 23 economically important traits
- fine-mapping results for 23 economically important traits
- SV genotypes of 208 ONT samples
- graph-based SV genotypes of 2,128 short-read samples

The graph pangenome supporting the findings of this study has been deposited in Zenodo and is available at:

https://doi.org/10.5281/zenodo.15549648

Recommended manuscript wording:

> All processed datasets generated in this study, including the reference genome and annotation files, SV site information, gene read counts, TPM expression matrices, significant variant-gene expression associations, GWAS and fine-mapping summary statistics, SV genotypes of 208 ONT samples, and graph-based SV genotypes of 2,128 short-read samples, are available through the PIGSVOME database Download page (https://pigsvome.bmyjy.org.cn/Help/Download).
