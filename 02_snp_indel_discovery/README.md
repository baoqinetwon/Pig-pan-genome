# 02_snp_indel_discovery

This module contains scripts for SNP and Indel discovery from genome assemblies and long-read sequencing data.

## Main scripts

### 1. `longread_snp_indel_detection.sh`

Detect SNPs and Indels from PacBio HiFi long-read data.

The workflow includes two main steps:

1. Align HiFi reads to the reference genome using `pbmm2 align --preset HIFI`
2. Call SNPs and Indels from the sorted BAM file using DeepVariant with `--model_type=PACBIO`

Example alignment command:

```bash
pbmm2 align \
    --preset HIFI \
    -j 52 \
    --sort \
    --sort-threads 52 \
    --sample BMA \
    /path/to/Duroc.mmi \
    BMA_hifi.fastq.gz \
    01_bam/BMA_pbmm.bam
```

Example DeepVariant command using GPU Singularity image:

```bash
singularity exec --nv --network=none -n deepvariant-gpu.1.4.0.sif \
    run_deepvariant \
    --model_type=PACBIO \
    --ref=/path/to/Duroc.fa \
    --reads=01_bam/BMA_pbmm.bam \
    --output_vcf=02_deepvariant/BMA_pbmm.vcf.gz \
    --num_shards=52
```

## Inputs

- PacBio HiFi FASTQ files, for example `BMA_hifi.fastq.gz`
- Reference genome FASTA, for example `Duroc.fa`
- pbmm2/minimap2 index, for example `Duroc.mmi`
- DeepVariant GPU Singularity image

## Outputs

- Sorted BAM files generated by pbmm2:

```bash
01_bam/${SAMPLE}_pbmm.bam
```

- SNP/Indel VCF files generated by DeepVariant:

```bash
02_deepvariant/${SAMPLE}_pbmm.vcf.gz
```

## Notes

- The script is written for PacBio HiFi data and uses the DeepVariant `PACBIO` model.
- GPU acceleration is enabled by adding `--nv` to `singularity exec`.
- Replace sample names, reference paths, index paths, and Singularity image paths according to the local computing environment.
